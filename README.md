# Wellnest AI

Minimal health and exercise chatbot website with:
- Dashboard mock smartwatch data
- AI chat page
- OpenRouter / Hermes 3 backend
- API key hidden in `.env`

## Run

```bash
npm install
npm start
```

Open:

```txt
http://localhost:3000
```

## Setup API key

Edit `.env`:

```env
OPENROUTER_API_KEY=your_key_here
```

Then restart server.
